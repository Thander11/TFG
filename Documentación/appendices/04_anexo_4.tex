\textbf{Carga y etiquetado de datos:} Los datos se extraen de archivos de texto, convirtiendo las lecturas de los sensores en vectores numéricos aplanados:

\begin{lstlisting}[language=Python, caption={Función para cargar y etiquetar los datos de entrenamiento.}, label={lst:keras_std_carga}]
drive.mount('/content/drive')

# Configuracion de rutas
bueno_dir = '/content/drive/MyDrive/Colab Notebooks/BUENO'
malo_dir = '/content/drive/MyDrive/Colab Notebooks/MALO'

X_features = []
y_labels = []

def cargar_sustancias(ruta_carpeta, etiqueta):
    conteo = 0
    for archivo in os.listdir(ruta_carpeta):
        if archivo.endswith(".txt"):
            ruta_completa = os.path.join(ruta_carpeta, archivo)
            try:
                # Carga con pandas, mas robusto para decimales ','
                datos_df = pd.read_csv(ruta_completa, sep=' ', 
                                       decimal=',', skiprows=1, header=None)
                # Convertir a numerico, forzando errores a NaN
                datos_df = datos_df.apply(pd.to_numeric, errors='coerce')
                # Convertir a numpy y aplanar
                datos = datos_df.values.flatten()

                if np.all(np.isnan(datos)):
                    print(f"Advertencia: '{archivo}' contiene solo NaNs.")
                else:
                    X_features.append(datos)
                    y_labels.append(etiqueta)
                    conteo += 1
            except Exception as e:
                print(f"Error en {archivo}: {e}")
    return conteo
\end{lstlisting}

En el \autoref{lst:keras_std_carga}, la función \texttt{cargar\_sustancias} (líneas 10--32) procesa cada archivo \texttt{.txt} de la carpeta especificada. La línea 17 lee el archivo con \texttt{pandas}, interpretando la coma como separador decimal y omitiendo la primera fila de metadatos. La línea 20 convierte todos los valores a numérico, forzando los errores a NaN. La línea 22 aplana la matriz a un vector unidimensional. Si el archivo contiene solo valores NaN, se ignora (líneas 24--25); en caso contrario, se añade a las listas de características y etiquetas.

\begin{lstlisting}[language=Python, caption={Homogeneización (Padding) de los datos.}, label={lst:keras_std_padding}]
# Cargar datos

n_malos = cargar_sustancias(malo_dir, 0)    # Clase Negativa

if X_features:

    padded_X_features = []

Debido a que las capturas tienen duraciones distintas, el \autoref{lst:keras_std_padding} muestra el proceso de homogeneización (líneas 6--15). Se encuentra la longitud máxima entre todos los arrays (línea 7), que resulta ser 242.676 características. Los arrays más cortos se rellenan con valores NaN hasta alcanzar esta longitud máxima (líneas 10--12), garantizando una matriz de características constante.

\textbf{División del dataset, imputación y escalado: } Los datos se dividen y preparan para el entrenamiento:

\begin{lstlisting}[language=Python, caption={División del dataset, imputación y escalado.}, label={lst:keras_std_split}]

X_train_val, X_test, y_train_val, y_test = train_test_split(

En el \autoref{lst:keras_std_split}, la primera división (líneas 2--4) reserva el 20\% de los datos para el test final, utilizando estratificación para mantener la proporción de clases. El \texttt{SimpleImputer} (líneas 7--9) reemplaza los valores NaN generados por el padding con ceros, ya que las redes neuronales no pueden procesar valores faltantes. El \texttt{StandardScaler} (líneas 12--14) normaliza los datos para que tengan media 0 y varianza 1, un paso fundamental para que las funciones de activación de Keras operen correctamente. Del 80\% restante, se utilizará un 20\% para validación durante el entrenamiento (configurado en el método \texttt{fit}), resultando en una distribución final aproximada de 64\% para entrenamiento, 16\% para validación y 20\% para prueba.

\textbf{Definición de la arquitectura de la red neuronal:} Se ha implementado un modelo de tipo Secuencial que permite un flujo de datos lineal a través de capas densas:

\begin{lstlisting}[language=Python, caption={Definición de la arquitectura de la red neuronal en Keras.}, label={lst:keras_std_model}]
# Definir la estructura de la red
model = Sequential([
    Dense(32, activation='relu', input_shape=(X_train_val_scaled.shape[1],)),
    Dropout(0.2),  # Ayuda a evitar el sobreajuste
    Dense(16, activation='relu'),
    Dense(1, activation='sigmoid')  # Salida binaria (0 a 1)
])

model.compile(optimizer='adam', loss='binary_crossentropy', 
    metrics=['accuracy'])

# Configurar parada temprana
early_stop = EarlyStopping(monitor='val_loss', patience=10, 
                           restore_best_weights=True)
\end{lstlisting}

La arquitectura consta de:
\begin{itemize}
    \item \textbf{Primera capa oculta} (línea 3): 32 neuronas con activación ReLU y entrada de tamaño 242.676 (determinado dinámicamente). Su función es realizar la primera abstracción de los datos del sensor.
    \item \textbf{Capa de Dropout} (línea 4): Con una tasa de 0.2 (20\%) para prevenir el sobreajuste durante el entrenamiento.
    \item \textbf{Segunda capa oculta} (línea 5): 16 neuronas con activación ReLU, que profundiza en la jerarquía de patrones detectados.
    \item \textbf{Capa de salida} (línea 6): Una única neurona con activación Sigmoide, que proyecta el resultado como una probabilidad entre 0 y 1.
\end{itemize}

El modelo se compila (línea 9) con el optimizador Adam y la función de pérdida \textit{Binary Cross Entropy}, adecuada para clasificación binaria. El \texttt{EarlyStopping} (líneas 12--13) detiene el entrenamiento si la pérdida de validación no mejora durante 10 épocas consecutivas, restaurando los mejores pesos encontrados.

\textbf{Entrenamiento del modelo:} El entrenamiento se realiza por lotes con validación interna:

\begin{lstlisting}[language=Python, caption={Entrenamiento del modelo con validación.}, label={lst:keras_std_train}]

    X_train_val_scaled, y_train_val,
    epochs=50,
    batch_size=5,
    validation_split=0.2,  # Divide internamente para validacion
    callbacks=[early_stop],

Como se muestra en el \autoref{lst:keras_std_train}, el entrenamiento se ejecuta durante un máximo de 50 épocas con un tamaño de lote de 5 muestras (líneas 5--6). Este tamaño pequeño permite una actualización más frecuente de los pesos, lo que puede ayudar a la convergencia del modelo con conjuntos de datos limitados. El parámetro \texttt{validation\_split=0.2} (línea 7) divide internamente el conjunto de entrenamiento, reservando el 20\% para validación.

\textbf{Bucle de entrenamiento con Early Stopping:} A diferencia de Keras, en PyTorch el bucle de entrenamiento se implementa manualmente:

\begin{lstlisting}[language=Python, caption={Bucle de entrenamiento con Early Stopping en PyTorch.}, label={lst:pytorch_std_train}]
epochs = 15
train_losses, val_losses = [], []
train_accuracies, val_accuracies = [], []

# Parametros para Early Stopping
early_stopping_patience = 10
best_val_loss = float('inf')
patience_counter = 0

for epoch in range(epochs):
    # Fase de entrenamiento
    model.train()
    running_loss = 0.0
    correct_train, total_train = 0, 0
    
    for inputs, labels in train_loader:
        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()
        running_loss += loss.item()
        
        predicted = (outputs > 0.5).float()
        total_train += labels.size(0)
        correct_train += (predicted == labels).sum().item()

    train_accuracy = 100 * correct_train / total_train
    train_losses.append(running_loss / len(train_loader))
    train_accuracies.append(train_accuracy)
\end{lstlisting}

En el \autoref{lst:pytorch_std_train}, el bucle de entrenamiento (líneas 10--30) itera sobre cada época. En la fase de entrenamiento (líneas 12--30), se activa el modo de entrenamiento (línea 12), se itera sobre los lotes del \texttt{DataLoader} (línea 16), se calcula la pérdida (línea 19), se propaga hacia atrás (línea 20) y se actualizan los pesos (línea 21). Las líneas 24--26 calculan la precisión del entrenamiento.

            correct_val += (predicted == labels).sum().item()

    val_accuracy = 100 * correct_val / total_val
    val_losses.append(val_loss / len(val_loader))
    val_accuracies.append(val_accuracy)

    # Logica de Early Stopping
    current_val_loss = val_losses[-1]
    if current_val_loss < best_val_loss:
        best_val_loss = current_val_loss
        patience_counter = 0
    else:
        patience_counter += 1
        if patience_counter >= early_stopping_patience:
            print(f"Early stopping en la epoca {epoch+1}.")
            break
\end{lstlisting}

En el \autoref{lst:pytorch_std_val}, la fase de validación (líneas 2--18) se ejecuta sin calcular gradientes (\texttt{torch.no\_grad()}) para ahorrar memoria. La lógica de Early Stopping (líneas 21--29) verifica si la pérdida de validación mejora; si no mejora durante 10 épocas consecutivas, el entrenamiento se detiene. %chktex 36

\section{Pseudocódigos}
A continuación se presentan los pseudocódigos de los procedimientos de entrenamiento implementados en Keras y PyTorch. Es el mismo para ambos modelos normales y aumentados, con la única diferencia en el dataset utilizado para el entrenamiento, y las etapas y tamaño de lote mencionados anteriormente.

\subsection{Keras}

\noindent\textbf{Algoritmo: Flujo de entrenamiento de la Red Neuronal para detección de sustancias (Keras).}

\begin{algorithmic}[1]
\State~\textbf{Entrada:} Archivos espectrales (.txt) en directorios \textit{BUENO} y \textit{MALO}
\State~\textbf{Salida:} Modelo clasificador optimizado en formato \@.keras y \@.tflite

\State~\textit{Fase 1: Preprocesamiento de Datos}{}
\State~Inicializar listas $X$ (características) e $y$ (etiquetas)
\For{cada archivo en directorios}%
    \State~Leer datos numéricos omitiendo metadatos
    \State~Aplanar matriz de datos a vector unidimensional
    \If{longitud $<$ $L_{\max}$}%
        \State~Aplicar \textit{Padding}{} con valores NaN hasta alcanzar $L_{\max}$%
    \EndIf%
    \State~Asignar etiqueta (1 para Bueno, 0 para Malo)
\EndFor%
\State~Imputar valores faltantes (NaN) utilizando estrategia de constante (0)
\State~Dividir dataset: 80\% Entrenamiento/Validación, 20\% Prueba Final

\State~\textit{Fase 2: Normalización}{}
\State~Calcular $\mu, \sigma$ de media y desviación estándar del conjunto de entrenamiento
\State~$X_{scaled} \leftarrow \frac{X - \mu}{\sigma}$ (Escalado estándar para convergencia de ANN)

\State~\textit{Fase 3: Construcción de la Red Neuronal Artificial}{}
\State~Definir arquitectura secuencial:
\State~\quad 1. Capa Densa (32 neuronas, activación ReLU, entrada de tamaño 242676)
\State~\quad 2. Capa Dropout (0.2) para evitar sobreajuste
\State~\quad 3. Capa Densa (16 neuronas, activación ReLU)
\State~\quad 4. Capa de Salida (1 neurona, activación Sigmoide)
\State~Configurar optimizador \textit{Adam}{} (tasa: 0.001) y función de pérdida \textit{Binary Crossentropy}{}

\State~\textit{Fase 4: Entrenamiento y Evaluación}{}
\State~Configurar \textit{Early Stopping}{} monitoreando la pérdida de validación
\State~Entrenar modelo por 50 épocas con tamaño de lote (\textit{batch}{}) de 5
\State~Evaluar precisión final en el conjunto de prueba (Test)

\State~\textit{Fase 5: Exportación}{}
\State~Guardar modelo en formato nativo Keras (.keras)
\State~Convertir modelo a TensorFlow Lite (.tflite) para despliegue móvil/embebido
\end{algorithmic}

\subsection{PyTorch}

\noindent\textbf{Algoritmo: Flujo de entrenamiento de la Red Neuronal para detección de sustancias (PyTorch).}

\begin{algorithmic}[1]
\State~\textbf{Entrada:} Archivos espectrales (.txt) en directorios \textit{BUENO} y \textit{MALO}
\State~\textbf{Salida:} Modelo clasificador optimizado en formato \@.pth y \@.tflite

\State~\textit{Fase 1: Preprocesamiento de Datos}{}
\State~Inicializar listas $X$ (características) e $y$ (etiquetas)
\For{cada archivo en directorios}%
    \State~Leer datos numéricos usando pandas
    \State~Convertir a numérico forzando errores a NaN
    \State~Aplanar matriz de datos a vector unidimensional
    \If{todos los valores son NaN}%
        \State~Ignorar archivo y mostrar advertencia
    \Else%
        \State~Añadir datos a $X$ y etiqueta (1 para BUENO, 0 para MALO) a $y$
    \EndIf%
\EndFor%
\State~Encontrar longitud máxima entre todos los arrays
\State~Rellenar (Padding) los arrays más cortos con valores NaN

\State~\textit{Fase 2: División del Dataset y Escalado}{}
\State~Dividir datos: 80\% Entrenamiento/Validación, 20\% Prueba Final (stratificado)
\State~Dividir 80\% en 75\% Entrenamiento, 25\% Validación (resultado: 60\%, 20\%, 20\%)
\State~Imputar valores faltantes (NaN) utilizando estrategia de constante (valor 0)
\State~Normalizar datos con \textit{StandardScaler} (media 0, varianza 1)
\State~Convertir datasets a tensores de PyTorch

\State~\textit{Fase 3: Construcción de la Red Neuronal Artificial}{}
\State~Definir clase \textit{OlfativaANN} heredando de \textit{nn.Module}:
\State~\quad 1. Capa Lineal (entrada$\rightarrow$32 neuronas)
\State~\quad 2. Activación ReLU
\State~\quad 3. Capa Dropout (0.2) para evitar sobreajuste
\State~\quad 4. Capa Lineal (32$\rightarrow$16 neuronas)
\State~\quad 5. Activación ReLU
\State~\quad 6. Capa Lineal (16$\rightarrow$1 neurona)
\State~\quad 7. Activación Sigmoide
\State~Inicializar modelo con dimensión de entrada = tamaño de características
\State~Configurar función de pérdida \textit{Binary Cross Entropy Loss}
\State~Configurar optimizador \textit{Adam} (tasa de aprendizaje: 0.001)

\State~\textit{Fase 4: Entrenamiento con Early Stopping}{}
\State~Configurar parámetros: épocas=15, tamaño de lote=5, paciencia=10 épocas
\State~Crear \textit{DataLoader} para entrenamiento y validación
\For{cada época hasta máximo de épocas}%
    \State~Modo entrenamiento: Forward pass, calcular pérdida, backward, actualizar pesos
    \State~Modo evaluación: Forward pass en conjunto de validación, calcular pérdida
    \If{pérdida de validación mejora}%
        \State~Reiniciar contador de paciencia
        \State~Guardar el mejor modelo (opcional)
    \Else%
        \State~Incrementar contador de paciencia
        \If{paciencia alcanzada}%
            \State~Detener entrenamiento (Early Stopping)
        \EndIf%
    \EndIf%
\EndFor%

\State~\textit{Fase 5: Evaluación en Conjunto de Prueba}{}
\State~Evaluar modelo en datos de prueba
\State~Calcular precisión y matriz de confusión
\State~Visualizar curvas de aprendizaje (Accuracy y Loss)

\State~\textit{Fase 6: Exportación del Modelo}{}
\State~Guardar modelo en formato PyTorch (.pth)
\State~Exportar modelo a ONNX (.onnx) usando \textit{torch.onnx.export}
\State~Cargar modelo ONNX y convertir a TensorFlow SavedModel
\State~Convertir TensorFlow SavedModel a TensorFlow Lite (.tflite)
\State~Guardar modelo TFLite para despliegue móvil/embebido
\end{algorithmic}
