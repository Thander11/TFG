\section{Configuración de ajustes}
Una vez instalada, es necesario configurar la aplicación para que los datos se reciban correctamente y la vista en la interfaz sea mas clara. Para acceder a los ajustes hay que pulsar el icono de las tres rayas horizontales en la esquina superior izquierda de la pantalla principal de la aplicación. A continuación, se debe seleccionar la opción \textit{Settings}. Una vez dentreo de los ajustes pueden verse cuatro pestañas: Terminal, Receive, Send y Misc. A continuación se describen los ajustes necesarios en cada una de las pestañas.

\subsection{Terminal}
Esta configuración puede verse en la Figura~\ref{fig:terminal_settings}.

\begin{itemize}
    \item \textbf{Font Size:} 14.
    \item \textbf{Font Style:} Normal.
    \item \textbf{Charset:} UTF-8.
    \item \textbf{Display mode:} Terminal.
    \item \textbf{Auto scroll to end of buffer:} Debe estar activado.
    \item \textbf{Show connection messages:} Debe estar activado.
    \item \textbf{Show timestamps:} Debe estar desactivado.
    \item \textbf{Buffer size:} Unlimited.
\end{itemize}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth]{pictures/Settings-terminal.jpg}
    \caption{Configuración de la pestaña Terminal.}\label{fig:terminal_settings}
\end{figure}

\subsection{Receive}
Como puede verse en la Figura~\ref{fig:receive_settings} esta pestaña solo cuenta con una opción (Newline) que debe ser CR+LF\@. 

\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth]{pictures/Settings-receive.jpg}
    \caption{Configuración de la pestaña Receive.}\label{fig:receive_settings}
\end{figure}

\subsection{Send}
Esta configuración puede verse en la Figura~\ref{fig:send_settings}.

\begin{itemize}
    \item \textbf{Newline:} CR+LF\@.
    \item \textbf{Edit mode:} Text.
    \item \textbf{Line delay:} 0.
    \item \textbf{Character delay:} 0.
    \item \textbf{Local echo:} Debe estar activado.
    \item \textbf{Clear input on send:} Debe estar desactivado.
\end{itemize}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth]{pictures/Settings-send.jpg}
    \caption{Configuración de la pestaña Send.}\label{fig:send_settings}
\end{figure}

\subsection{Misc}

Esta configuración puede verse en la Figura~\ref{fig:misc_settings}.

\begin{itemize}
    \item \textbf{Macro buttons:} 2 Rows.
    \item \textbf{Keep screen on when connected:} Debe estar activado.
    \item \textbf{Show notification when connected:} Opcional activarlo o no.
    \item \textbf{Save + log folder:} Indica la ruta donde guardar los archivos si quieres guardarlos en el móvil.
    \item \textbf{Hints:} No es configuración, es un boton para mostrar recomendaciones.
\end{itemize}
