\section{Configuración de ajustes}
Una vez instalada, es necesario configurar la aplicación para que los datos se reciban correctamente y la vista en la interfaz sea más clara. Para acceder a los ajustes hay que pulsar el icono de las tres rayas horizontales en la esquina superior izquierda de la pantalla principal de la aplicación. A continuación, se debe seleccionar la opción \textit{Settings}. Una vez dentro de los ajustes pueden verse cuatro pestañas: Terminal, Receive, Send y Misc. A continuación se describen los ajustes necesarios en cada una de las pestañas.

\subsection{Terminal}
Esta configuración puede verse en la~\autoref{fig:terminal_settings}.

\begin{itemize}
    \item \textbf{Font Size:} 14.
    \item \textbf{Font Style:} Normal.
    \item \textbf{Charset:} UTF-8.
    \item \textbf{Display mode:} Terminal.
    \item \textbf{Auto scroll to end of buffer:} Debe estar activado.
    \item \textbf{Show connection messages:} Debe estar activado.
    \item \textbf{Show timestamps:} Debe estar desactivado.
    \item \textbf{Buffer size:} Unlimited.
\end{itemize}

\begin{figure}[H]
    \centering
    \shadowbox{\includegraphics[width=0.6\textwidth]{pictures/Settings-terminal.jpg}}
    \caption{Configuración de la pestaña Terminal.}\label{fig:terminal_settings}
\end{figure}

\subsection{Receive}
Como puede verse en la~\autoref{fig:receive_settings} esta pestaña solo cuenta con una opción (Newline) que debe ser CR+LF\@.

\subsection{Send}
Esta configuración puede verse en la~\autoref{fig:send_settings}.

\begin{itemize}
    \item \textbf{Newline:} CR+LF\@.
    \item \textbf{Edit mode:} Text.
    \item \textbf{Line delay:} 0.
    \item \textbf{Character delay:} 0.
    \item \textbf{Local echo:} Debe estar activado.
    \item \textbf{Clear input on send:} Debe estar desactivado.
\end{itemize}

\subsection{Misc}

Esta configuración puede verse en la~\autoref{fig:misc_settings}.

\begin{itemize}
    \item \textbf{Macro buttons:} 2 Rows.
    \item \textbf{Keep screen on when connected:} Debe estar activado.
    \item \textbf{Show notification when connected:} Opcional activarlo o no.
    \item \textbf{Save + log folder:} Indica la ruta donde guardar los archivos si quieres guardarlos en el móvil.
    \item \textbf{Hints:} No es configuración, es un boton para mostrar recomendaciones.
\end{itemize}

\section{Conexión con la nariz electrónica}
Para conectar la aplicación con la nariz electrónica, primero hay que volver a pulsar las tres rayas horizontales en la esquina superior izquierda de la pantalla principal de la aplicación. A continuación, se debe seleccionar la opción \textit{Devices}. Aparecerá una lista con los dispositivos Bluetooth disponibles, como se ve en la~\autoref{fig:lista_dispositivos}. Además en la esquina superior derecha está el botón ``SCAN'' para volver a buscar dispositivos. Hay que seleccionar el dispositivo correspondiente a la nariz electrónica (en este caso \textit{nosecrisE4}) y esperar a que se establezca la conexión. Una vez conectado, se puede volver a la pantalla principal de la aplicación para comenzar a recibir datos.

\begin{figure}[H]
    \centering
    \shadowbox{\includegraphics[width=0.45\textwidth]{pictures/Lista-dispositivos.jpg}}
    \caption{Lista de dispositivos Bluetooth disponibles.}\label{fig:lista_dispositivos}
\end{figure}

\section{Configuración de botones}
Para facilitar la toma de muestras, se pueden configurar los botones macros en la parte inferior de la pantalla principal de la aplicación. Para ello simplemente hay que mantener pulsado el botón que se desea configurar hasta que aparezca la pantalla de configuración del botón, como se ve en la~\autoref{fig:configuracon_boton}. 
\par

Una vez en la pantalla de configuración, es posible encontrar varios parámetros:
\begin{itemize}
    \item \textbf{Name:} Nombre del botón (por ejemplo, ``Start'' o ``Stop'').
    \item \textbf{Value:} Comando que se enviará al dispositivo al pulsar el botón (por ejemplo, ``Exper'' o ``STOP'').
    \item \textbf{Edit mode:} Tipo de envío, debe estar en ``Text''.
    \item \textbf{Action:} Puede ser ``Send'', para que el comando se envíe automáticamente, o ``Insert'', para que el comando se inserte en el campo de texto sin enviarse (Este último se usa para enviar comandos que requiere que se escriba algún parámetro antes de enviarlo).
\end{itemize}

\begin{figure}[H]
    \centering
    \shadowbox{\includegraphics[width=0.65\textwidth]{pictures/Boton_config.jpg}}
    \caption{Pantalla de configuración de un botón macro.}\label{fig:configuracon_boton}
\end{figure}

Para un uso normal de la nariz electrónica, se recomienda configurar al menos los botones que se muestran en la~\autoref{tab:botones_macros}.
